03 — Play

Synthesis

패드를 클릭하거나 키보드 A~L 키를 눌러 직접 연주해보세요. 각 패드는 OscillatorNode를 새로 만들어 짧은 엔벨로프로 재생하고, 배경 톤과 합쳐진 스펙트럼이 중앙의 구체를 왜곡하고 파티클을 밀어냅니다.

Waveform
코드 모드: 켜면 패드 하나로 근음과 3도, 5도가 함께 울립니다.

스텝을 클릭하면 다음 음, Shift+클릭은 이전 음. 포커스한 스텝에서 ↑↓로 바꾸고 Delete로 비우거나 A~L 키로 바로 지정할 수 있습니다.

Built with

소리 하나, 파이프라인 하나.

  • Three.js
  • Web Audio API
  • GSAP ScrollTrigger
  • TypeScript
  • Vite

모든 소리는 OscillatorNode로 합성되며 외부 음원 파일은 사용하지 않습니다. 배경 톤과 연주음은 하나의 마스터 GainNode를 거쳐 하나의 AnalyserNode로 모이고, 화면의 모든 움직임은 그 노드에서 매 프레임 읽은 실제 값입니다.
